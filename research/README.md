# Research — 知识层

> 这里放"**我们知道什么**"，不放"**我们主张什么**"。
> 一句话边界：**别人的论文进 `reference/`，我们的知识状态进这里。**

---

## 1. 四个位置

| 位置 | 放什么 | 判定 |
|---|---|---|
| [`briefs/`](briefs/) | 定向调研简报（带 Sources、带"对 WAM 的含义"） | 有出处、可复核的事实整理 |
| [`external-assets.md`](external-assets.md) | 外部可借鉴工作的核实与取舍（A/B/C 核实分级 + adopt/adapt/defer/reject） | 对**外部材料**的判断，不是我们的决定 |
| [`notes/`](notes/) | 作者脑暴、会议现场、卡片、原话墙 | 一手材料，**不求结论完整** |
| [`archive/raw-archive.md`](archive/raw-archive.md) | 392 个文件的原文汇编（3.5 MB） | 只读归档；**内部链接不可解析是正常的**，原文照录 |

## 2. 与 `reference/` 的边界

| | `research/`（这里） | `reference/`（同级） |
|---|---|---|
| 对象 | 我们的调研、我们的材料 | **外部论文本身** |
| 流程 | 无固定流程，有出处即可 | 六阶段：入库 → 评估 → 提案 → 验证 → 整合 → 回访 |
| 产物 | 简报、取舍表、笔记 | 论文条目（方法 / 实验 / 局限 / 与 WAM 的映射 / 评估标准） |
| 权重分档 | 无 | critical / enhancement / noise |
| 什么时候用 | 想知道"我们查到过什么" | 想引用/借鉴一篇具体论文 |

**同一条外部结论出现两处 = 边界失效。** 处理：留 `reference/` 的条目，`research/` 只写指针。

## 3. 这里的东西不能直接当结论用

研究材料进入正式主张，必须走两步：

1. 成为**提案**：`directions/<name>/`（一行假设 + 证伪条件）；
2. 或被**采纳**：`workspace/decisions.md` 记事件 + `docs/decisions/register.md` 记状态。

**Research 里的任何判断都不构成决定**，包括 `external-assets.md` 里的 adopt/reject 评级——那是"值得试"的判断，不是"已经定了"。

## 4. 归档材料的维护规则

- `archive/raw-archive.md` 是原文照录：**不改写、不去重、不修内部链接**。
- 任何全仓链接检查**必须排除它**，否则永远报 33 处断链（2026-11-10 审计已确认这是唯一一类断链）。
- 需要引用其中内容时，引用**原始文件路径**（文件内每段都有 `SOURCE` 标注），不引用汇编的行号。
